# 📊 NovaTech Electronics — Sales Analytics Dashboard

A Microsoft Excel project focused on **Sales Analysis, Data Cleaning, KPI Development, Business Analysis, and Interactive Dashboarding** using synthetic sales transaction data.

## 📌 Project Overview

Developed an interactive **Sales Analytics Dashboard** using Microsoft Excel to analyze sales performance across:

* Products
* Categories
* Regions
* Customers
* Salespeople
* Monthly sales trends

The project follows an end-to-end workflow:

**Raw Sales Data → Data Cleaning & Validation → Business Analysis → KPI Development → Interactive Dashboard → Business Insights**

> **Note:** The dataset used in this project is synthetic sales transaction data created for portfolio and learning purposes. NovaTech Electronics is a fictional company name used to represent the business scenario.

The main objectives of this project were to:

## 🧹 Data Cleaning & Validation

The raw sales data was cleaned and validated before performing the analysis.

The cleaning process included:

* Removed extra spaces.
* Standardized inconsistent Region values.
* Filled blank Discount values with `0`.
* Calculated missing Quantity values where possible.
* Calculated missing Unit Price values where possible.
* Validated Sales calculations.
* Documented data-cleaning changes in a **Cleaning Log** maintained in the main workbook.
